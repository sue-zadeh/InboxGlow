# InboxGlow product listing kit

## Suggested title

**InboxGlow — Animated React Contact Form & Admin Inbox**

## Short description

A polished full-stack contact experience with an animated React interface, secure Node.js API, PostgreSQL storage, and a protected message dashboard.

## Product-page copy

Turn a basic contact form into a professional first impression. InboxGlow gives agencies, freelancers, SaaS teams, and local businesses a responsive contact page plus a practical admin inbox for reviewing enquiries.

The code is organised, typed, documented, and ready to customise. Buyers can change the brand, colours, contact details, and enquiry types from one configuration file. A static demo mode is included for marketplace previews.

### Highlights

- React 19, TypeScript, Vite, and Framer Motion
- Node.js, Express, Prisma, and PostgreSQL
- Secure HTTP-only admin session
- Search, filter, mark-read, archive, and CSV export
- Client and server validation
- Rate limiting, spam honeypot, Helmet, controlled CORS, and size limits
- Mobile responsive and keyboard accessible
- Docker, migrations, tests, linting, CI, and deployment guides
- Privacy, terms, commercial licence, support, and security templates
